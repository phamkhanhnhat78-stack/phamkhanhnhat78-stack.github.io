AWS Three-Tier Web Architecture

Problem

Design a reliable web application environment that separates public access, application compute, and database storage.

Build Plan

Tools

AWS VPC, ALB, EC2, Auto Scaling, RDS, IAM, security groups, route tables, architecture documentation.
