# KHANHNHAT PHAM Portfolio Website

Personal portfolio website for cloud systems, IT infrastructure, Python automation, and technical project work.

## Project Structure

```text
phamkhanhnhat78-stack.github.io/
├── index.html              # Homepage for GitHub Pages
├── about.html              # About page
├── assets/
│   └── css/
│       └── styles.css      # Shared website styling
└── README.md               # Project notes and structure
```

## Pages

- `index.html`: Main portfolio page with profile summary, featured projects, technical skills, and current learning direction.
- `about.html`: Professional background, quick facts, and working style.

## Preview Locally

Open `index.html` directly in a browser, or use VS Code Live Server if installed.

## Deployment

This repository is designed for GitHub Pages. Keep `index.html` in the project root so GitHub Pages can load the homepage correctly.
